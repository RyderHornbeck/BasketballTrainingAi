# HoopPlan (frontend)

Expo React Native app for HoopPlan, an AI basketball workout planner. See the
project root `README.md` for the full setup guide (Supabase migrations, video
import, Edge Function deploy, EAS builds).

## Quick start

```bash
npm install
npm start
```

Requires `frontend/.env` with:

```env
EXPO_PUBLIC_SUPABASE_URL=
EXPO_PUBLIC_SUPABASE_ANON_KEY=
```
